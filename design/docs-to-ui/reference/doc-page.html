Petstore Plus API

OpenAPI Generated January 15, 2026

Overview

The Petstore Plus API provides comprehensive pet management capabilities for retailers and shelters. Access inventory, process orders, and manage customer relationships through a consistent REST interface.

  • Browse and filter pets by availability status
  • Create and update pet records with photos and descriptions
  • Process adoption orders and track fulfillment
  • Manage user accounts and preferences

All endpoints require authentication via the X-API-Key header. Visit the authentication guide for setup instructions.

get /pets

List available pets

ℹ️
Not enriched
Only the original API description is shown. Enrichment adds usage examples and parameter guidance.

Returns a paginated list of pets matching the specified filters. Results are sorted by availability and creation date.

Parameters

Name In Type Required Default Description
limit query integer — 20 Maximum number of pets to return (1–100).
status query string — — Filter by availability: available, pending, sold.
X-Request-Id header string — — Optional request tracking identifier.

Examples

curl -X GET "https://api.petstore.example/v1/pets?limit=10&status=available" \
  -H "X-API-Key: your_api_key_here" \
  -H "Accept: application/json"
import requests

response = requests.get(
    "https://api.petstore.example/v1/pets",
    params={"limit": 10, "status": "available"},
    headers={"X-API-Key": "your_api_key_here"}
)
pets = response.json()
{

      "id": "pet_12345",
      "name": "Luna",
      "species": "dog",
      "breed": "Golden Retriever",
      "age": 2,
      "status": "available"
    }
  ],
  "total": 47,
  "page": 1,

}

Returns

Returns a paginated list of pet objects with total count and pagination metadata.

post /pets

Create a new pet record

Creates a new pet in the system. Requires name, species, and breed. Photos can be uploaded separately via the media endpoint.

Parameters

Name In Type Required Default Description
name body string required — Pet's name (2–50 characters).
species body string required — One of: dog, cat, bird, rabbit, other.
breed body string required — Breed or mix description.
age body integer — — Age in years.

Examples

curl -X POST "https://api.petstore.example/v1/pets" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Max",
    "species": "dog",
    "breed": "Labrador",
    "age": 3
  }'
import requests

response = requests.post(
    "https://api.petstore.example/v1/pets",
    headers={"X-API-Key": "your_api_key_here"},
    json={
        "name": "Max",
        "species": "dog",
        "breed": "Labrador",
        "age": 3
    }
)
pet = response.json()
{
  "id": "pet_67890",
  "name": "Max",
  "species": "dog",
  "breed": "Labrador",
  "age": 3,
  "status": "available",
  "created_at": "2026-01-15T14:23:00Z"
}

Returns

Returns the created pet object with assigned ID and timestamps.

delete /pets/{petId}

Remove a pet from inventory

Permanently removes a pet record and all associated media. This action cannot be undone. Active orders for this pet will be canceled.

Parameters

Name In Type Required Default Description
petId path string required — Unique pet identifier.

Examples

curl -X DELETE "https://api.petstore.example/v1/pets/pet_12345" \
  -H "X-API-Key: your_api_key_here"
import requests

response = requests.delete(
    "https://api.petstore.example/v1/pets/pet_12345",
    headers={"X-API-Key": "your_api_key_here"}
)
result = response.json()
{
  "success": true,
  "message": "Pet pet_12345 has been deleted",
  "canceled_orders": 2
}

Returns

Returns confirmation with count of any canceled orders.
